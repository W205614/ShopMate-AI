# 设计记录

> 历史归档：保留该阶段的实现和验收记录，其中的能力、接口与测试数量不代表当前版本。当前入口见 [文档导航](../README.md)。

## 方向与内容依据

- 指定 skill：`design-taste-frontend`，方向 `contact-sheet`，seed `20261016`，完整抽取结果保存在 `docs/archive/design-direction.json`。没有重抽。
- 调色：Sheet and biro，白 `#fff`、墨色 `#111`、浅灰 `#f4f4f4`、蓝 `#1a4be0`。Libre Franklin 用于品牌与标题，正文统一使用系统无衬线字体，中文按设备回退；品牌字体文件本地提供。首版抽取的 Source Serif 4 正文搭配在本次全站复审中停用，以统一商城、表单和后台的阅读风格，未重抽方向。
- 对象清单：ShopMate 名称中的伙伴、六类百货、24件商品目录、商品与咨询的上下文、用户与运营两种视角、购物清单、订单凭据、库存变动、收支记录、规则客服和人工接待。
- 核心句：在此页面，ShopMate 的购物伙伴成为连接商品目录和咨询上下文的线索。它表达当前产品能力，不声称具有其他电商没有的独占概念。
- 页面论证：看见有什么（完整图片目录）→ 从生活品类缩小范围（分类索引）→ 说出需求（可操作规则推荐）→ 查看具体价格与商品（推荐区）→ 购物后找答案（带上下文客服）。没有虚构客户、评价、媒体标志或销售证明。

## 实现与适用边界

首页使用密集图片目录及一次放大的商品展示；指向目录条目时更新预览文案和图片反馈，手机直接显示。表单、商品列表、购物车和管理台保留实际应用界面的交互习惯，管理表格使用 Element Plus，后台不会进入商城首屏依赖。

首版文案草稿已由页面实现与本设计记录取代，不再单独维护。商品和品牌资料属于演示样例。图片来自开放许可摄影，作者、许可和出处在 `/credits` 可逐项查看，没有把素材作者或原图品牌当成本站合作方。

动效使用目录入场、控件反馈和商品图片缓慢变化；减少动态效果模式下显示完整静态内容。已搜索陶瓷制作片段，结果来自与本项目无关的真实工坊；本期不使用，以免让演示商品看起来出自该工坊。inspector 的无视频 WARN 因此保留；没有为通过检查器添加无关视频。

## 视觉复审

按 skill 的 1440/768/390px 截图流程检查，三轮内完成修订。第一轮主要问题是标题上方的小字与字号层级太多；第二轮修复无障碍跳转链接的几何误识别、目录末项与下一节的距离，并将首页字号收敛为五类；最后补充手机首屏的明确实色入口。

检查覆盖焦点、构图、品牌关联、对齐、空间、字体、配色、图片、布局变化、手机、完整度、内容、碰撞与交互。最终评分和检查输出以 `verification.md` 的实际结果为准，不将自动规则通过视为设计质量证明。

仍有局限：开放素材光线与背景不完全一致，部分商品只有一张图，创意核心属于常见的目录与购物伙伴表达；未来真实品牌落地时应替换为同一拍摄标准的产品素材，完善真实规格与政策。

## 用户复审后的首页调整

用户指出两行大标题过于抢眼、右侧留白过多，因此将首页从展示型大字改为电商目录的紧凑信息层级：桌面标题 32px、手机 24px，默认标语保持单行；移除重复的大品牌字，补充桌面快捷分类，并将全部商品入口与目录标题放在同一行。手机保留菜单和原有分类页入口，避免重复的六类快捷导航占用首屏。

参考了 [Shopify 官方主题设计规范](https://shopify.dev/docs/storefronts/themes/best-practices/design)中导航清晰、商品入口可发现的原则。淘宝页面被浏览器站点安全策略阻止读取，拼多多公开页也未成功读取，没有将其当前具体布局当作已核实资料。

这项明确的用户偏好优先于 skill 的营销页焦点规则。检查时以 `--allow focal-point` 显式记录例外；不重新放大标题，也不添加无关大图来通过该规则。原始抽取方向文件保持原样，白、黑、蓝配色和商品目录主体继续保留。

## 全站字号与间距复审

用户进一步要求统一用户端与管理端的阅读密度。本轮保留原配色、商品摄影、导航和业务流程，将商城页标题统一为桌面32px、手机24px，分区22/20px；管理页标题28/24px、分区20/18px，表格正文14px。全局 token 位于 `frontend/src/style.css`，移动端保留44px触控区域，正文没有随标题一起缩小。

详情页限制图片高度并完整展示商品；购物车、结算、订单、个人中心、售后与客服减少重复外边距。页脚从巨大品牌铺屏改为紧凑服务区，短页面自然贴底。购物车、结算与支付结果不显示悬浮客服，避免遮挡操作；导航、页脚与订单/商品专属咨询入口继续可用。管理端收紧主区、卡片和顶栏，设置表单限制宽度，空客服面板按内容收敛；手机日期弹层改为纵向可滚动日历。

三档页面、表单和会话状态的范围、具体发现及复审记录见 [全站界面复审](ui-review.md)。巨大字号、120–220px营销展示间距及图片数量规则只适用于展示页，不用于订单、表单、客服和真实管理表格。
