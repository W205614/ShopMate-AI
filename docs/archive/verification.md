- skill 源码 lint：0 FAIL；保留的零填充 WARN 仅用于图片 ID 和日期，不用于界面索引编号。
- inspector：1440、768、390px，0 个未豁免 FAIL；保留一个无视频 WARN，原因见设计说明。用户复审要求缩小首页标题，使用 `--allow focal-point` 记录营销页巨大焦点规则的例外。
- 首页 32 张图片元素（含重复展示），桌面五种可见字号角色（13/16/22/26/32px），默认主标题为32px单行、手机24px单行，所有标题最多两行。检测到24个真实动效元素；没有用静态占位符代替商品图片。
- 已实际查看桌面、平板、手机首屏和分屏截图，以及商品详情、后台概览和商品管理。截图位于 `docs/screenshots/`，可通过 `node frontend/scripts/capture.mjs` 重建。
- 首页保留导航与内容区客服入口，取消与推荐按钮争抢空间的额外悬浮客服；购物车、结算和支付页同样取消悬浮按钮以免遮挡交易操作，其他业务页保留快捷入口。
- 管理侧栏曾在 Edge 整页截图中漏绘图标；DOM 和区域截图均正常，管理桌面文档截图改用视口截图，页面本身无需修补。

依据 skill 量表的人工自评（非外部评审）：设计 7.5、可用性 8、创意 6.5、内容 7.5，加权 **7.45 / 10**。优点是完整商品目录、统一布局和真实闭环；限制是开放素材背景不完全统一、部分商品单图、品牌辨识和创意仍可继续深化。

本轮继续覆盖全部用户端和管理端，基础30个页面/状态×三档宽度，改动前后各90张视口截图及标题、页面高度、横向溢出测量。三档均无页面横向溢出；长管理表格在自身区域滚动。另增加21张地址与售后表单、待支付、带商品上下文会话、商品SKU与手机日期浮层截图，最终共111张。具体范围与取舍见 [全站界面复审](ui-review.md)。390px日期浮层完整落在视口内，实际点选起止日期通过；商品保存按钮可滚动到达。

## 明确边界

生产构建仍提示管理端懒加载包超过 500KB；没有提高阈值隐藏提示，后台组件未进入商城首屏。生产依赖审计不覆盖容器系统包、业务安全或整个供应链。

浏览器本地存储无法代替服务端数据库；角色和归属校验只是交互演示，开发者工具能访问完整数据。不支持跨设备同步、真实认证、支付、物流、大模型、生产财务或多商家。真实图片的品牌、规格与虚构商品参数无对应保证，均有演示说明及独立许可署名。

## GitHub 与运行版本

CI 配置位于 `.github/workflows/validation.yml`；提交后应按当前远程提交 SHA 核对运行结果。最终提交 SHA 与 CI 链接在交付消息中报告，避免在提交内部记录自身 SHA。

镜像支持 `VCS_REF` 构建参数，并以 `org.opencontainers.image.revision` 记录版本。交付时以最终提交 SHA 重建并核对容器标签；该标签本身不代替浏览器与构建验证。
