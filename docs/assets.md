# 商品示意图与素材许可

本项目为单店电商演示，账号及业务数据由后端持久化。图片展示对应物品或使用场景，不代表 ShopMate-AI 实际经营、生产或获得品牌授权的商品；商品名称、价格、库存和规格为演示数据。画面中的品牌文字属于原图内容，未表达合作或背书关系。

所有 24 张图片保存在 `frontend/public/images/p01.jpg` 至 `p24.jpg`，运行时不请求外部图库。素材通过指定 design-taste-frontend skill 的 `scripts/assets.mjs` 查询 Commons 与 Openverse，后以 Openverse 元数据补充筛选。来源和许可元数据核对日期：2026-10-16。StockSnap 与 rawpixel 结果所标的 CC0 来自 Openverse 记录；原始来源未提供作者时如实标明，未推断作者。

## 图片来源

[图片署名清单](../frontend/public/images/credits.json)记录每张图片的演示用途、原始标题、作者、许可、来源链接和本地 JPEG 的 SHA-256。运行商城后可访问 `/credits` 逐项浏览，或访问 `/images/credits.json` 获取同一份记录。

## 使用与处理

- 仅进行等比缩小、JPEG 编码和文件重命名；没有更改主体、移除标识、重着色或合成。最长边至多 1000 像素；保留原始宽高比例，页面可通过 CSS 裁切显示。
- CC BY / CC BY-SA 的署名应保留标题、作者、源页和许可链接，站内“素材来源”页直接读取署名清单展示这些信息。
- CC BY-SA 图片的当前压缩版本继续按各自原许可提供；项目代码的许可不替代图片许可。
- 本批没有使用 AI 生成图片，没有热链图片，没有视频素材；商城可使用照片的轻微位移动效，并提供减少动态效果回退。

## 替换真实商品图片

上线真实商城前，将演示图片、商品信息及示例价格替换为对应商品的自有或已获授权资料，并同步维护来源清单。
