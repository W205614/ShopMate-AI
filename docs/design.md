# 设计记录

## 方向与内容依据

- 指定 skill：`design-taste-frontend`，方向 `contact-sheet`，seed `20261016`，完整抽取结果保存在 `.taste-skill/direction.json`。没有重抽。
- 调色：Sheet and biro，白 `#fff`、墨色 `#111`、浅灰 `#f4f4f4`、蓝 `#1a4be0`。Libre Franklin 用于标题，Source Serif 4 用于拉丁正文，中文回退系统字体；字体文件本地提供。
- 对象清单：ShopMate 名称中的伙伴、六类百货、24件商品目录、商品与咨询的上下文、用户与运营两种视角、购物清单、订单凭据、库存变动、收支记录、规则客服和人工接待。
- 核心句：在此页面，ShopMate 的购物伙伴成为连接商品目录和咨询上下文的线索。它表达当前产品能力，不声称具有其他电商没有的独占概念。
- 页面论证：看见有什么（完整图片目录）→ 从生活品类缩小范围（分类索引）→ 说出需求（可操作规则推荐）→ 查看具体价格与商品（推荐区）→ 购物后找答案（带上下文客服）。没有虚构客户、评价、媒体标志或销售证明。

## 实现与适用边界

首页使用密集图片目录及一次放大的商品展示；指向目录条目时更新预览文案和图片反馈，手机直接显示。表单、商品列表、购物车和管理台保留实际应用界面的交互习惯，管理表格使用 Element Plus，后台不会进入商城首屏依赖。

文案先行稿在 `frontend/src/views/shop/design-copy.txt`。商品和品牌资料属于演示样例。图片来自开放许可摄影，作者、许可和出处在 `/credits` 可逐项查看，没有把素材作者或原图品牌当成本站合作方。

动效使用目录入场、控件反馈和商品图片缓慢变化；减少动态效果模式下显示完整静态内容。已搜索陶瓷制作片段，结果来自与本项目无关的真实工坊；本期不使用，以免让演示商品看起来出自该工坊。inspector 的无视频 WARN 因此保留；没有为通过检查器添加无关视频。

## 视觉复审

按 skill 的 1440/768/390px 截图流程检查，三轮内完成修订。第一轮主要问题是标题上方的小字与字号层级太多；第二轮修复无障碍跳转链接的几何误识别、目录末项与下一节的距离，并将首页字号收敛为五类；最后补充手机首屏的明确实色入口。

检查覆盖焦点、构图、品牌关联、对齐、空间、字体、配色、图片、布局变化、手机、完整度、内容、碰撞与交互。最终评分和检查输出以 `verification.md` 的实际结果为准，不将自动规则通过视为设计质量证明。

仍有局限：开放素材光线与背景不完全一致，部分商品只有一张图，创意核心属于常见的目录与购物伙伴表达；未来真实品牌落地时应替换为同一拍摄标准的产品素材，完善真实规格与政策。
