# 企业交付补全与发布记录（2026-11-06）

本记录汇总单店生产版后续的交付优化。初次功能验收见[单店生产版本地验收](production-acceptance-20261106.md)。

## 本轮变更

- 发布前覆盖运行中、已停止旧容器及保留数据库卷，使用目标镜像生成验证快照和图片恢复集；失败保留维护。
- 解除维护前核对 API/Web 实际镜像 ID、提交标签、健康与生产模式；恢复发布要求维护标记与目标提交一致。
- 配置检查和实际 Compose 使用相同插值配置；公网健康需返回正确 JSON，而非仅 HTTP 成功。
- 补齐架构、接口、上线核对和贡献说明，并启用 GitHub 私密漏洞报告。
- 支付与退款恢复命令绑定请求标识和原参数；回调重复重试不能重置后续失败轮次。
- 物流任务在外部网络前可靠占用尝试预算并绑定任务，进程中断也遵守五次上限。
- 启用短信必须同时配置验证及交易模板，缺失时明确失败，避免静默丢失订单通知。
- 用户正常改密时，同事务撤销旧会话及已签发的验证挑战，旧找回密码凭证不能覆盖新密码。
- 管理员退出同时撤销未完成的 MFA 挑战，并清除新旧 Cookie 路径，退出后的旧挑战不能继续登录。
- 协议正文按版本不可变保存；不能回退复用旧版本号改变正文，原文不可得的已同意历史版本保留占位。协议版本记录纳入备份摘要与恢复校验。
- 同浏览器切换账号后重建安全面板、清理私有草稿并拦截旧异步响应；账号 A 的迟到导出不会交给 B，旧撤销或注销响应不会清除 B 会话。
- 跨标签登录时，旧会话请求可能短暂返回未登录；仅对应用自身发起的鉴权重定向恢复原受保护页面，用户主动打开登录页或退出不会被自动带回。
- 迁移对照识别旧账号 `active` 和旧会话 `mfa_verified` 缺列时的合法默认状态，仍逐项核对原字段及既有启停、MFA 状态；不会把新增默认列误报为凭据变更。

供应商接入和真实支付、云服务仍按[实网验收清单](integrations.md#本地验证与实网验收)处理。

## 验证与发布证据

执行 `git rev-parse HEAD` 获取目标提交，并在本仓库 GitHub Actions 中查看对应的 CI 结果。

部署主机在私有审计文件 `.delivery/enterprise-release-20261106/final-report.json` 中保存本地回归、应用提交、CI、实际镜像与容器、恢复资产、清理回执及最终运行状态。该文件由部署主机保留。

| 证据             | 核对方式                                                                                                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 应用提交与 CI    | 当前应用完整 SHA、该 SHA 对应 Actions run 和实际结论                                                                                                                         |
| 定向本地验证     | 发布脚本与 preflight、账号安全、支付及外部服务定向验证通过；完整用例数、全量结果、修复复核和跳过原因以主机审计为准                                                               |
| 全量回归         | 主机审计记录测试范围、环境、结果、失败修复及跳过原因                                                                                                                         |
| 最终 API/Web     | 主机审计的 image ID、revision、运行内容校验及容器健康                                                                                                                        |
| 升级、清理与停止 | 已执行的升级步骤、清理对象、保护范围、回执和最终运行状态                                                                                                                             |
| 恢复资产         | 具体已核验的升级前快照及恢复前提；本机备份偏好保留                                                                                                                           |

发布与失败恢复按[生产指南](production.md#首次发布与升级)执行。数据库升级和二进制版本不兼容时，不直接换回旧镜像；应停写、保留当前状态并核对外部资金，再按匹配恢复集处理。
