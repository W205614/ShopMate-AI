# v0.1.0 发布前检查（2026-11-07）

首个语义化版本发布单店商城源码。版本覆盖 Vue、Express、SQLite、单 API、演示交易及可配置的生产供应商适配；生产部署仍需完成自身商户、域名、公网回调和外部服务验收。

## 本轮修改

- 原创代码与文档采用 MIT，保留图片、字体和依赖各自的许可与署名。
- 前端构建使用 Vite 内置功能生成实际打包依赖的许可正文，输出至 `licenses/dependencies.md`；API/Web 镜像携带项目 LICENSE。
- 前端 Vitest 改为最多两个线程，解决本机默认进程池启动超时；保留每个测试文件的隔离和全部断言。
- Docker 构建上下文额外排除私钥、SQLite 文件、日志、Python 缓存和 TypeScript 增量文件。
- 开发指南将业务数据版本修正为 v5，并说明 v4 降级所需的恢复集与资金核对；补齐贡献、支持范围和第三方分发说明。

## 升级与已知限制

现有 v5 部署没有新增数据库迁移。更早的 v4 实例按[生产升级流程](production.md#首次发布与升级)先准备一致快照、图片恢复集、原密钥及匹配镜像，隔离演练后再切换；仅更换旧镜像不能回退 v5 数据。

本次为源码发布，不发布 npm 包、GitHub Packages、容器镜像附件或生产部署。默认模拟支付、合成 AI 和 SMTP/S3 协议测试不代表真实供应商验收。真实支付退款、短信、物流、云存储、模型质量、告警送达及云端恢复由部署者按[接入清单](integrations.md#本地验证与实网验收)完成。Caddy 的固定配置与 OpenVEX 边界见[入口评估](security/production-edge-vex.md)。

保留本机关闭自动备份的覆盖配置；已有恢复集是特定时间点的资产，不提供持续恢复点。日常容器保持原有停止状态，隔离测试不写入业务卷。本轮不重复生产容量压测，历史压测结果及条件沿用原报告。
