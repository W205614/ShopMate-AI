# v0.1.2 AI 商品检索与容器分发维护

日期：2026-11-09，时区 Asia/Shanghai。维持单店、单 API、SQLite 架构；修复 AI 商品检索的中文误匹配，并补齐容器分发。没有新增依赖或数据库迁移。

## 中文商品检索修复

真实调用诊断中，模型查询 `保温杯`，商品工具却返回马克杯、咖啡豆、植物皂等部分含字的商品。已通过直接调用真实工具复现：旧逻辑把连续中文拆为单字，匹配任意一字即可进入结果。

本轮将连续中文保留为完整关键词，沿用既有排序、价格、在售和可用库存约束。不存在的 `保温杯` 返回空数组；`水杯`、`马克杯` 分别匹配对应商品，不再因共享单字混入其他商品。没有增加模型重试、备用回答或调用预算。

旧实现新增回归失败；修复后五个相关测试文件 55/55、后端类型检查通过。使用内存隔离库和真实工具实现，无供应商调用。最终提交的完整回归、镜像和源码材料以对应 GitHub Actions 结果为准。

## 容器分发

本轮补齐 API/Web 的容器分发入口：日常 Compose 可以通过 `API_IMAGE`、`WEB_IMAGE` 使用已验证镜像，默认源码构建方式继续可用。新增手动发布工作流，要求目标 Tag 与成功验证 CI 的提交一致，推广同一验收镜像，拒绝主动覆盖已有版本。

镜像分发材料包括实际 Alpine 包及构建配方/源文件、Node.js 与 Nginx 源码、sharp-libvips 组件源码和构建脚本、依赖许可与摘要。准备失败会中止发布，不把根项目 MIT 或漏洞扫描结果当成第三方分发许可。获取方式及发布步骤见[容器分发](container-distribution.md)。

目标为公开 [v0.1.2 Release](https://github.com/W205614/ShopMate-AI/releases/tag/v0.1.2) 和 [API](https://github.com/users/W205614/packages/container/package/shopmate-ai-api)、[Web](https://github.com/users/W205614/packages/container/package/shopmate-ai-web) 两个 GHCR Packages，平台为 Linux/amd64。最终发布摘要、CI、本机升级结果在 Release 和本机交付记录中核实；本说明不提前代表发布或验收成功。

本机升级保留原业务数据、配置和账号，自动备份及副本仍关闭，原来停止的容器验收后恢复停止。代表性交易流程使用隔离数据验证；日常实例只读核对。真实模型、支付、通知、物流、云存储和生产部署仍按既有边界另行验收，本轮不声称它们已通过。

## 真实模型诊断边界

本轮使用内存隔离库、合成账号和持久化预算代理验证现有 `gpt-6-luna`：首轮授权 3 次，均返回 HTTP 200 并执行商品查询，但未形成最终回答，用量 5,253 tokens。经另行授权追加 4 次诊断，确认模型反复发送同一 `search_products` 查询，服务端确已按原 `tool_call_id` 回传结果，最终按原四次上限失败，追加用量 8,112 tokens。

该诊断发现并复现了上述本地检索缺陷；不能由此证明它是重复调用的唯一原因。两轮共 7 次真实请求，均未产生业务提案。修复后尚未追加付费复测，真实模型最终回答质量仍未验收通过；脱敏轨迹和预算账本保留在本机。合成 AI 契约与本地工具回归不替代该结论。
