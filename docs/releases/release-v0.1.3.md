# v0.1.3 AI 循环收敛与镜像启动

日期：2026-11-09，时区 Asia/Shanghai。维持单店、单 API、SQLite 架构；本版本将 AI 重复搜索与最终回答的修复纳入 API/Web 容器分发，同步 README 的免编译启动入口。没有新增依赖或数据库迁移。

## AI 查询与最终回答

原控制器四次请求均允许继续调用工具，模型重复同一商品搜索时可能耗尽预算而没有最终回答。现在同一轮成功的相同参数商品搜索（含空结果）复用已返回的数据，重复出现后下一次请求进入最终回答阶段；不同参数和失败查询不复用。第四次模型请求也保留用于最终回答，设置标准 `tool_choice: none` 并保持 JSON 模式。

提示要求已有事实足够时结束查询，空结果转人工。最终回答仍须通过结构、证据和权限校验，商品及订单事实读取当前业务状态；业务变更继续通过顾客确认的提案执行。原四次调用、八次工具及总期限上限不变，没有增加模型重试或预设兜底回答。
