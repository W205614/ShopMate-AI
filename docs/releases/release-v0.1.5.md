# v0.1.5 AI 定向修复与入口安全维护

日期：2026-11-12，Asia/Shanghai。继续采用单店、单 API、SQLite 架构，没有数据库迁移、新服务或新的应用依赖。

## 修复内容

- 中文商品检索复用现有分词，保留完整关键词并增加多字词匹配和排序，解决“桌面收纳用品”整段短语漏查已有商品的问题；保留不新增单字扩展的回归约束。
- 政策回答必须为每个知识引用选择完整相关原句，不再在缺少摘录时展示整段来源。保留逐字、句子边界、否定词和同句条件校验；完整来源仍可展开核对。
- 缺少摘录或把商品 ID 当作知识引用 ID 时，使用原有四次请求上限内的格式纠正，不增加调用预算、业务兜底或自动重试上限。
- 生产 edge 的构建器固定至官方 Go 1.27.4 摘要，修复本轮扫描发现的 CVE-2026-97054；保留此前 Caddy 安全依赖修复、全部标准模块及原有配置。依据与历史扫描边界见 [入口安全说明](../security/production-edge-security.md)。

## 验证与模型调用边界

发布前修复提交的本地定向回归 46/46、类型及格式检查通过。真实模型以隔离合成数据完成推荐与两项政策问答的累计定向复测，保留初跑和修复过程中的失败记录，没有重跑完整十二场景，也没有人工质量评分。该修复轮累计 17 次对话／Embedding／Reranker 请求，实际账单未知。详细事实见 [定向修复记录](ai-fix-20261112.md)。

本次发布和本机升级不再追加模型、Embedding、Reranker 或视觉请求。版本准备只同步分发说明，复用相同 AI 源码的既有真实证据；最终提交的 CI 仍执行无付费合成服务的应用与 AI 契约回归。CI 首次修复提交曾被 edge 的原始漏洞门禁阻断，修复 Go 标准库后成功；最终发布源的结果以对应 Actions 为准，不把此前失败改述为首次通过。

## 分发与部署

目标版本为公开正式 [v0.1.5 Release](https://github.com/W205614/ShopMate-AI/releases/tag/v0.1.5)，以及公开 Linux/amd64 API/Web 镜像：

```dotenv
API_IMAGE=ghcr.io/w205614/shopmate-ai-api:v0.1.5
WEB_IMAGE=ghcr.io/w205614/shopmate-ai-web:v0.1.5
```

发布工作流核对 Tag、源码提交与成功 CI，推广同一 CI 镜像及对应源码材料，不重新构建、不覆盖旧版本、不更新 `latest` 或部署生产。Release 随附 `container-sources-v0.1.5.tar.gz`、`SHA256SUMS`；许可与获取方式见 [容器分发](../container-distribution.md)。实际发布摘要与完成状态以 Release、发布工作流及本机交付记录为准，本说明不提前代表发布成功。

API/Web 镜像不包含生产 Caddy。生产 edge 使用者须从本版本源码按安全说明重新构建并完成自身环境验收；没有发布独立 edge Package，也没有公网 ACME 或生产部署验收。v0.1.4 及更早制品保持原有版本边界。

本机升级使用本次发布的同一制品，保留原配置、账号、业务卷和关闭自动备份的策略。健康及只读页面验收期间阻止外部 AI 调用；完成后恢复原 AI 配置与原停止状态。数据库一致副本、完整性、外键和业务表摘要的实际结果单独记录，不用隔离验收冒充日常升级成功。
