# v0.1.7 日常维护修复

本版面向单店商城的本机日常使用，沿用单 API、SQLite 和现有数据卷。没有新增数据库迁移、服务或运行依赖。

- 取消待付款订单时，页面和 AI 客服以服务端回执区分已取消与等待渠道关单。关单中保留预占，顾客可回到订单详情核对最终状态。
- 财务仍可查订单及退款流水，服务端按角色返回配送资料。渠道退款页面明确说明填写顾客沟通内容的入口，再次购买提示使用可售库存。
- AI 选购使用服务端识别的明确预算筛选有货规格。咨询和文档入口告知外部处理范围，外发文本会对常见联系方式和带标签的地址做脱敏处理。
- 打开的经营概览会定期刷新超时统计。

## 镜像与验收范围

应用镜像为 `ghcr.io/w205614/shopmate-ai-api:v0.1.7` 和 `ghcr.io/w205614/shopmate-ai-web:v0.1.7`，支持 Linux/amd64。镜像摘要、许可和对应源码见本版本 Release。升级前保留现有配置、业务卷和匹配的一致恢复资料。

本轮验收范围为个人日常场景，使用隔离数据、模拟交易和合成模型响应。真实商户联调、客户数据合规评审、外部通知送达和生产上线演练按[接入清单](../integrations.md#本地验证与实网验收)安排。
