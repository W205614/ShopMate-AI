# 2026-10-20 各角色实际流程验收

本轮使用浏览器驱动真实 HTTP 服务，覆盖顾客、店主、运营、仓储、客服、财务。写入式容器验收在独立 Compose 项目 `shopmate-roles-final-20261020`、端口 `18095` 和独立数据卷中执行；日常部署 `18086` 未用于创建测试交易或员工。

## 发现与修复

| 问题 | 结果 |
| --- | --- |
| 售后处理按钮只判断业务状态，其他员工也看到审核、收货或退款入口，提交后返回 403 | 页面及提交入口同时检查权限；客服审核、仓储收货、财务退款，并说明当前交接职责 |
| 运营能看评价，但也看到后端只允许客服执行的隐藏按钮 | 运营保持只读，客服和店主保留隐藏及恢复展示操作 |
| 仓储、财务的订单详情提供无权限访问的评价链接 | 按目的页面权限显示关联入口 |
| 财务历史采购流水提供无权限进入的库存记录链接 | 财务保留历史 SKU 关联说明与分工提示，店主仍能定位库存记录 |
| 新页面直接访问无权限的库存、优惠券等地址时，集合读取先失败，身份未完成同步，页面误报连接故障 | 读取前过滤无权限集合，保留已核实身份，由路由显示无权访问 |

后端授权规则未调整。各员工的有效业务请求仍按服务端权限检查；回归也直接验证了越权请求返回 403。
