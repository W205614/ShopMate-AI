浏览器本地存储无法代替服务端数据库；角色和归属校验只是交互演示，开发者工具能访问完整数据。不支持跨设备同步、真实认证、支付、物流、大模型、生产财务或多商家。真实图片的品牌、规格与虚构商品参数无对应保证，均有演示说明及独立许可署名。

## GitHub 与运行版本

CI 配置位于 `.github/workflows/frontend.yml`；提交后应按当前远程提交 SHA 核对运行结果。最终提交 SHA 与 CI 链接在交付消息中报告，避免在提交内部记录自身 SHA。

镜像支持 `VCS_REF` 构建参数，并以 `org.opencontainers.image.revision` 记录版本。交付时以最终提交 SHA 重建并核对容器标签；该标签本身不代替浏览器与构建验证。
